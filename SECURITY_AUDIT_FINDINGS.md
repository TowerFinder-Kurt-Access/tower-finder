# Security Audit Findings — Tower Finder
**Branch:** `audit/security-review`
**Date:** 2026-08-28
**Method:** Agent-driven via CLI. Repo + shell + full git history + read-only production DB via Prisma (`prisma_migration` role, ~3s connect).
**Threat model:** Previous developer hostile. Assume deliberate backdoor until proven otherwise.

## Summary

- **Files scanned:** `src/` (135 files), `scripts/` (56), `experiments/` (7), `prisma/`, `vercel.json`, `.github/`, `package.json`/lockfile, git history (-S scans, 100 commits), live DB (`pg_catalog`, `information_schema`, `pg_stat_activity`, `User`, `JobQueue`, `LoginEvent`, etc.)
- **Total API routes:** 42 files
- **Pass:** 27 authenticated/cron/intentionally-public
- **Fail — no auth at handler level:** 12 (7 still blocked by middleware 302, but defense-in-depth missing; 5 fully open even via middleware)
- **Backdoors planted:** None found — no `eval`/`new Function`/`child_process`/`exec`/obfuscated code, no hidden tables/triggers/functions, no rogue outbound to unknown host. See clean sections below.
- **Highest risk:** Unauthenticated DB reads/writes + cost burn on paid APIs + cron fail-open + superuser DB role + weak script defaults. All are exploitable now, but none hides a second credential or exfil beacon.

## Hardening notes (recurring)

- **Least-privilege DB role:** Ship `scripts/create-least-priv-role.sql` and run in CI before deploy. App URL uses `tower_app`, migrations use `prisma_migration`. Add DB-object allowlist check as cron: `SELECT tablename FROM pg_tables WHERE schemaname='public' EXCEPT SELECT model FROM expected_allowlist` + triggers/functions diff.
- **Cron secret-only:** Remove admin-session fallback on cron OR make it audited: log `isAdmin=true cron trigger` with userId. Require Bearer; never accept `?secret=` query. Add `failClosed` test: unset `CRON_SECRET` → handler returns 500/401, not 200.
- **API authz pattern:** Default is `await getAuthUser()` at top of every handler; ADMIN-only uses `await requireAdmin()`. Never rely on middleware 302 alone — return 401 from handler. Add shared `requireAuthOrCron(request)` helper. Lint rule / code-review checklist: every `src/app/api/**/route.ts` must call one of them;CI could grep.
- **Export + PII routes:** Rate-limit + role-gate mass export. `towers/export`, `owners/*`, `owner`, `nearby-parcels` are high-PII/high-cost — add per-user daily quotas.
- **Sentry hygiene:** Lower `tracesSampleRate`, add `beforeSend` scrub for secrets + phone numbers + owner names.
- **Dependency hygiene:** Weekly `npm audit`, Dependabot alerts on, `xlsx` pinned to safe version.
- **Secret scans:** Pre-commit `gitleaks protect` + CI `gitleaks detect`, plus `trufflehog`. Block `*.env` from ever being staged (`pre-commit: git diff --cached --name-only | grep -q "^\.env$" && exit 1`).
