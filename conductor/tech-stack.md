# Technology Stack: Tower Finder 4900

## Core Technologies
- **Language:** TypeScript (v5.9+)
- **Frontend Framework:** Next.js (v16+) using React (v19+)
- **Backend Framework:** Next.js API Routes (NextAuth v5 Beta)
- **UI Framework:** Material-UI (MUI v7+) with Emotion
- **Database ORM:** Prisma (v6+)
- **Database:** PostgreSQL

## Key Libraries & Tools
- **Maps:** Leaflet & React-Leaflet
- **Authentication:** NextAuth.js (v5)
- **Data Grid:** MUI X Data Grid
- **Error Tracking:** Sentry
- **Environment Management:** Dotenv
- **File Parsing:** Papaparse & XLSX

## Architecture & Workflow
- **Monorepo:** A unified Next.js project structure for both the frontend and backend.
- **API Strategy:** Next.js server actions and API routes for data fetching and mutations.
- **ORM Workflow:** Prisma for schema management, migrations, and type-safe database access.
